## Why

OpenSpec хранит изменения, спецификации и чеклисты в репозитории, но в bb нет специализированного представления этих данных как задач. Плагин позволит видеть прогресс и контекст работы рядом с агентными тредами; его собственный репозиторий станет первым примером использования.

Статус: первая версия согласована; реализация по спецификациям этого изменения.

## What Changes

В первой версии:
- Панель OpenSpec выбранного проекта и checkout/environment: список изменений и поиск.
- Карточка изменения: proposal, specs, design, tasks; отсутствующие артефакты видны явно.
- Чеклист с группами и прогрессом из tasks.md только для чтения. Статусы и артефакты обновляет агент в ходе работы; плагин отображает актуальное состояние без ручного редактирования.
- Отображение внешних изменений файлов после работы агента или пользователя.
- Привязка существующего треда к изменению и открытие контекста из треда.
- Создание и запуск треда для выбранного change: проработка, реализация или проверка; перед отправкой можно изменить первое сообщение и выбрать агента. Окружение наследуется от открытого change.
- Активные и архивные изменения доступны раздельно.

Для обсуждения после базовой версии: доска, создание изменений и архивация через интерфейс, отдельное представление всех пунктов tasks.md.

## Capabilities

### New Capabilities


- `openspec-change-browser`: просмотр изменений и их артефактов в контексте проекта и окружения.
- `openspec-task-checklist`: просмотр групп задач, их статусов и прогресса без ручного редактирования.
- `openspec-thread-context`: явная связь изменения с тредами bb.

### Modified Capabilities

Нет: директория до начала исследования была пустой, существующих спецификаций нет.

## Impact

Новый самостоятельный плагин bb с frontend/backend и, если потребуется для файлов на машинах, host entry. OpenSpec остаётся источником содержимого и прогресса; служебные связи с тредами хранятся отдельно. Зависимость от Tasks не предполагается.

Основная единица — change с вложенными задачами; чеклист только для чтения с Unicode-индикаторами. Запуск агента создаёт тред в выбранном существующем окружении. Первая версия поддерживает стандартную структуру артефактов spec-driven. Макет: docs/mockups/openspec-browser-v2.html; исследование: docs/research/bb-task-plugins.md.
