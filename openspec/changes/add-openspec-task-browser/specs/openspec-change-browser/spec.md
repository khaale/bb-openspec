## Purpose

Предоставляет пользователю bb просмотр изменений OpenSpec и их артефактов в выбранном окружении проекта без дублирования содержимого репозитория.

## ADDED Requirements

### Requirement: Выбор источника и просмотр изменений
Плагин SHALL показывать активные и архивные изменения стандартной структуры OpenSpec в выбранном окружении проекта, поиск по названию и идентификатору, наличие proposal/specs/design/tasks и прогресс задач. При переключении окружения данные SHALL относиться только к новому источнику.

#### Scenario: Просмотр изменений проекта
- **WHEN** пользователь выбирает проект и окружение с openspec/changes
- **THEN** плагин показывает изменения этого окружения и позволяет открыть каждое из них

#### Scenario: OpenSpec отсутствует или недоступен
- **WHEN** в окружении нет OpenSpec либо чтение завершилось ошибкой
- **THEN** интерфейс показывает соответствующее пустое состояние или ошибку с возможностью повторить загрузку

### Requirement: Просмотр артефактов
Плагин SHALL показывать Markdown выбранного артефакта и список спецификаций по capability. Отсутствующие артефакты SHALL быть обозначены явно. Плагин MUST ограничивать чтение каталогом OpenSpec выбранного окружения.

#### Scenario: Просмотр спецификаций
- **WHEN** пользователь открывает Specs изменения с несколькими capability
- **THEN** он может выбрать и прочитать соответствующий spec.md

#### Scenario: Недопустимый путь
- **WHEN** запрос пытается прочитать файл вне OpenSpec выбранного окружения
- **THEN** плагин отклоняет запрос

### Requirement: Обновление внешних изменений
Открытый интерфейс SHALL автоматически перечитывать содержимое OpenSpec после изменений, выполненных агентом или пользователем, и предоставлять ручное обновление.

#### Scenario: Агент обновил задачи
- **WHEN** агент изменяет tasks.md открытого изменения
- **THEN** интерфейс обновляет список задач и прогресс без перезагрузки приложения
