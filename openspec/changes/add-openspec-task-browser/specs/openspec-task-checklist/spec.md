## Purpose

Показывает группы задач OpenSpec и их выполнение рядом с артефактами изменения, оставляя управление состоянием задач агенту и исходным файлам.

## ADDED Requirements

### Requirement: Чеклист только для чтения
Плагин SHALL отображать задачи из tasks.md с группами и Unicode-индикаторами ✓ и ○, количеством выполненных задач и общим прогрессом. Пользователь MUST NOT изменять отметки или содержимое задач через плагин. Кодовые блоки MUST NOT интерпретироваться как реальные задачи.

#### Scenario: Выполненные и оставшиеся задачи
- **WHEN** tasks.md содержит выполненные и невыполненные пункты
- **THEN** интерфейс показывает ✓ и ○, верные счётчики и не предлагает интерактивных чекбоксов

#### Scenario: Задач пока нет
- **WHEN** tasks.md отсутствует или не содержит отслеживаемых задач
- **THEN** интерфейс показывает отсутствие задач и предлагает проработать изменение с агентом
