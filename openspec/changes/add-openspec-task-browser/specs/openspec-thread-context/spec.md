## Purpose

Связывает изменения OpenSpec с тредами bb, позволяя запускать агентную работу с контекстом выбранного изменения и возвращаться к соответствующему треду.

## ADDED Requirements

### Requirement: Запуск агента для изменения
Плагин SHALL создавать видимый тред для активного change в выбранном окружении проекта. Перед отправкой пользователь SHALL выбирать проработку, реализацию или проверку, настройки агента и редактировать первое сообщение. Плагин MUST NOT запускать агента без явного действия пользователя. Реализация SHALL быть недоступна при отсутствии задач.

#### Scenario: Запуск реализации
- **WHEN** пользователь подтверждает запуск реализации change с задачами
- **THEN** создаётся связанный тред в том же окружении с выбранными настройками и сообщением, содержащим контекст change

#### Scenario: Ошибка запуска
- **WHEN** создание треда завершается ошибкой
- **THEN** форма сохраняет ввод и показывает ошибку без автоматического повторного запуска

### Requirement: Связи с существующими тредами
Пользователь SHALL привязывать существующий тред из того же окружения к change, видеть связанные треды с текущими статусами и открывать их. Привязка MUST NOT отправлять сообщение агенту. Тред SHALL предоставлять доступ к связанному изменению.

#### Scenario: Привязка существующего треда
- **WHEN** пользователь выбирает тред того же окружения и подтверждает привязку
- **THEN** тред появляется в карточке change без запуска нового хода агента

#### Scenario: Переход из треда
- **WHEN** пользователь открывает OpenSpec в связанном треде
- **THEN** отображается связанное изменение в окружении этого треда
