## Context

bb собирает Git-плагин после npm install --omit=dev --omit=optional --ignore-scripts. Рабочая установка с devDependencies не проверяет этот контракт. Один плагин расположен в корне; его ID openspec, версия 0.4.0.

## Decisions

- Проверять production-сборку во временной копии рабочих файлов без node_modules, dist и .git. Рабочая установка и bb state не изменяются.
- Закрепить CLI bb-app для CI; CI не содержит шагов публикации и не требует прав записи.
- Сохранить русскую документацию, основной README сделать английским.
- Зафиксировать отдельно условия готовности Git-релиза и будущей заявки Community. Адрес репозитория, аккаунт, теги и категория каталога заполняются на соответствующем этапе.

## Risks / Trade-offs

Проверка production-сборки требует сети для npm и первого получения toolchain bb. Заявка в marketplace потребует актуальной проверки схемы и новых широких скриншотов; существующие изображения README не считаются готовым комплектом заявки.
