## Why

Плагин работает из локальной директории, но установка из Git использует другой набор зависимостей. До передачи публичного репозитория нужно проверить этот путь и подготовить документацию для пользователей и сопровождающих.

## What Changes

- Проверка сборки в чистой копии с production-зависимостями и отключёнными lifecycle scripts.
- CI проверок без публикации, английский README с русской версией и инструкция будущего релиза из Git.
- Описание плагина в формате, пригодном для будущей заявки в Community.
- Лицензия после выбора владельца; URL репозитория и автор не выдумываются.

## Capabilities

### New Capabilities
- `plugin-distribution`: воспроизводимая подготовка Git-установки и документация релиза.

### Modified Capabilities

Нет изменений runtime-поведения.

## Impact

Локальные scripts, devDependencies, документация и CI. Push, теги, npm publish и заявка в marketplace в этот change не входят.
