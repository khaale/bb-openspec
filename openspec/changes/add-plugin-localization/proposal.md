## Why

Интерфейс плагина сейчас содержит встроенные русские строки и не подходит англоязычным пользователям. В установленном SDK bb нет общего locale API, поэтому нужен собственный небольшой слой локализации с возможностью последующего подключения к bb.

## What Changes

- Настройка language: auto / en / ru в стандартных настройках плагина; Auto использует предпочтения текущего браузера, с английским fallback.
- Типизированные каталоги английских и русских UI-сообщений, локализация подсказок, accessibility labels, статусов, форм и собственных ошибок.
- Intl для чисел и форм множественного числа. Изменение языка без перезапуска и без сброса выбранного change или редактируемого prompt.
- Английский стартовый prompt и служебные инструкции, независимые от UI locale. Сохранение языка содержимого репозитория, пользовательских имён, редактируемого prompt и сообщений внешнего CLI; native-компоненты bb остаются на языке bb.

## Capabilities

### New Capabilities
- `openspec-localization`: выбор языка и локализованный интерфейс плагина.

### Modified Capabilities
Нет; существующие capabilities пока описаны в незархивированных changes.

## Impact

Frontend и shared сообщения/ошибки, настройка bb, тесты и документация. Без новых runtime dependencies, изменений OpenSpec файлов пользователя и глобального document.lang приложения bb.
