## ADDED Requirements

### Requirement: Выбор языка интерфейса
Плагин SHALL предоставлять настройку language auto/en/ru через bb settings. Auto SHALL выбирать поддерживаемый язык из navigator.languages текущего клиента и English при отсутствии совпадений. Изменение настройки и languagechange SHALL обновлять UI без перезагрузки.

#### Scenario: Язык выбирается автоматически
- **WHEN** настройка auto и браузер предпочитает ru-RU
- **THEN** интерфейс русский, а для неподдерживаемого набора языков используется английский

#### Scenario: Переключение без потери состояния
- **WHEN** пользователь меняет язык при открытом change или редактировании первого сообщения
- **THEN** подписи обновляются без сброса выбранного change, формы и текста prompt

### Requirement: Локализация собственных сообщений
Все собственные подписи, подсказки, accessibility labels и статусы SHALL иметь en/ru каталоги с одинаковыми ключами. Собственные кешированные ошибки SHALL локализоваться в момент отображения. Форматы чисел и множественное число SHALL использовать Intl.

#### Scenario: Кешированная ошибка и счётчики
- **WHEN** интерфейс меняется с ru на en после получения собственной ошибки
- **THEN** ошибка отображается на английском без повторного запроса данных
- **AND** формы 1/2/5/21 задачи соответствуют выбранной локали

### Requirement: Язык содержимого независим от UI
Смена UI locale MUST NOT переводить файлы репозитория, пользовательские названия, редактируемый prompt, инструкции агента и внешние ошибки. Плагин MUST NOT менять document.lang всего bb.

#### Scenario: Содержимое остаётся исходным
- **WHEN** английский UI показывает русскую спецификацию и пользовательский prompt
- **THEN** текст содержимого и prompt остаются неизменными

### Requirement: Английский стартовый шаблон
Новые шаблоны первого сообщения и служебный контекст агента SHALL быть английскими независимо от UI locale. Они SHALL требовать соблюдения языка артефактов из инструкций проекта. Текст уже редактируемого prompt MUST NOT перезаписываться при смене языка.

#### Scenario: Русский UI и английский стартовый prompt
- **WHEN** пользователь открывает форму запуска в русском UI
- **THEN** подписи формы русские, а новый шаблон prompt английский и сохраняет пути репозитория без перевода
