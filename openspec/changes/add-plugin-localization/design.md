## Context

SDK 0.6.79 предоставляет declarative plugin settings и reactive useSettings, но не locale/catalog API. Plugin-owned UI отделён от native pickers bb; RPC и host index могут хранить сообщения об ошибках дольше, чем текущий язык интерфейса.

## Decisions

- Настройка language auto/en/ru хранится в bb.settings. В Auto предпочтения navigator.languages разрешаются на клиенте; languagechange обновляет выбор. Неизвестные языки дают English fallback.
- Словари en/ru имеют одинаковые типизированные ключи; React context предоставляет t, Intl.NumberFormat и plural helpers. Locale принадлежит каждому frontend render tree, а не глобальному серверному singleton.
- Собственные ошибки передаются с устойчивым message key и параметрами внутри сообщения Error, сохраняя английский читаемый текст для CLI. Frontend декодирует ключ при показе, поэтому смена языка переводит и кешированную ошибку без повторного чтения файлов. Внешние ошибки сохраняются как есть.
- Дефолтные группы без Markdown heading и отсутствие имени треда/окружения обозначаются пустой строкой; UI локализует fallback, не сравнивая и не переводя пользовательские заголовки.
- Новые стартовые шаблоны и служебные инструкции агента всегда английские, без локализации. Они требуют соблюдать язык артефактов из project instructions. UI locale не меняет уже редактируемое первое сообщение, содержимое tasks/specs и имена проектов/stores. Названия, описания и варианты настроек всегда английские.
- Date formatter не добавляется: в текущем UI нет дат. Intl используется для отображаемых чисел и счётчиков задач/спецификаций.

## Risks / Trade-offs

Метаданные bb и native-компоненты могут остаться английскими. RPC strings для собственных ошибок получают код-маркер; клиенты вне UI видят английское сообщение. Auto различается между браузерами на одном сервере, явный language setting общий для плагина. Собственный контекст не меняет locale bb.
