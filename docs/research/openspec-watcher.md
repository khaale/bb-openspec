# Обновление OpenSpec по событиям

## Решение

В версии 0.2 используется native watcher Plugin SDK на машине окружения и индекс в памяти host worker. Первая загрузка сканирует имена файлов и читает tasks.md. При обычном изменении перечитывается только затронутый tasks.md; изменение документа инвалидирует его просмотр. Создание/удаление обновляет список имён, сохраняя разобранные неизменившиеся задачи. При потере событий/reconnect выполняется rescan. В простое нет таймера и чтения файлов.

Один путь проекта использует один watcher независимо от числа панелей. Последняя закрытая подписка освобождает watcher и индекс. Если openspec отсутствует, наблюдение за родительским каталогом обнаруживает его создание. Ошибка watcher отображается в панели; ручное обновление повторяет подключение. Состояния тредов обновляются отдельно через события bb.

## Измерения на praxis и lore

Локально, 2026-10-28. Репозитории использованы только для чтения. Семь запусков; таблица — медиана шести повторов после первого. Кеш ОС не сбрасывался. Замеры не включают RPC, рендеринг и debounce watcher.

| Операция, мс | praxis (52 архивных) | lore (1 активный + 33 архивных) |
|---|---:|---:|
| readFile + разбор всех tasks.md, без обхода каталогов | 5.46 | 2.86 |
| Первоначальный индекс: обход, проверки путей, чтение задач | 48.56 | 23.84 |
| Обработка одного изменённого tasks.md | 3.82 | 1.79 |
| Чтение готового индекса без изменений | <0.01 | 0.01 |
| Отдельный процесс `openspec list --json` | 363.44 | 378.02 |

При первоначальной индексации прочитано 52 / 34 файла задач; при обновлении — ровно один, в простое — ноль. Размер всех файлов задач: praxis 438173 байта, lore 109125 байт; максимальный файл — 27903 / 8774 байта.

CLI list перечисляет только активные изменения, поэтому его результат не эквивалентен индексу с архивом. На lore `status --json` занимает 404.94 мс, `instructions apply --json` — 363.83 мс. У status поле isComplete относится к готовности плановых артефактов, а прогресс реализации доступен через apply. Проверенная версия CLI отклоняет archive/... как имя change. Замена чтения CLI в текущем файловом браузере увеличивает задержку процесса и не покрывает архив.

Оставлено прямое readFile + существующий parser, без rg, потоковых библиотек и новых runtime-зависимостей. Важнее устранить повторные чтения, чем усложнять разбор небольшого изменившегося файла.

Воспроизводимость: `npx tsx scripts/benchmark-openspec.ts /absolute/repo/path`. Скрипт ничего не записывает в исследуемый репозиторий. Обновление одного файла моделируется событием для существующего файла, без изменения его содержимого.
