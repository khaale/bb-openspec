# Проверка первой версии

Дата: 2026-10-28. Плагин `openspec` версии 0.1.0 установлен из корня этого проекта; состояние bb — running.

## Автоматические проверки

- 13 тестов: разбор групп и маркеров задач, fenced/indented code examples, изоляция путей, active/archive, обновление прогресса, чтение артефактов, предел размера документа, отсутствие OpenSpec и недоступная машина.
- Через штатный SDK harness проверены запуск треда в выбранном окружении с настройками и изменённым сообщением, отказ запуска реализации без задач и запуска архивного change, привязка без отправки сообщения, отказ привязки из другого окружения.
- Проверка импортов подтверждает использование публичного SDK и vendored UI.
- TypeScript typecheck, `bb plugin types --check`, сборка и `openspec validate add-openspec-task-browser --strict` пройдены.

## Живой интерфейс bb

- Плагин отображает собственное изменение `add-openspec-task-browser` и три capability specs.
- Проверены чтение Markdown, список спецификаций, Unicode-статусы и read-only чеклист.
- Проверена форма запуска: действия, первое сообщение, стандартные picker-компоненты модели и разрешений.
- Исправлены выявленные при интеграции проблемы: необязательные undefined-поля в RPC и отсутствие токена --brand в стандартной теме bb. Цвет акцента берётся из доступных theme tokens.
- Текущий тред привязан к change; он отображается в связанных тредах. Проверены переход к треду и открытие его изменения через панель OpenSpec.
- После изменения tasks.md панель автоматически обновила прогресс с 5/8 до 6/8 без ручного обновления и перезагрузки.

## Ограничения проверки

Реальный новый агентный ход из формы не запускался. Создание треда и параметры запроса проверены через SDK harness; живьём проверена форма и чтение настроек bb. Другие машины и пользовательские схемы не проверялись. Границы первой версии и лимиты описаны в README.md.
