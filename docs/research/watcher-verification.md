# Проверка версии 0.2.0

Дата: 2026-10-28. Установленный plugin openspec 0.2.0, SDK 0.6.79.

## Автоматические проверки

- TypeScript: `npm run typecheck` — успешно.
- `npm test`: 20 тестов, все проходят.
- `npm run build`: server/app/host bundles собраны.
- `openspec validate watch-openspec-files --strict --no-interactive`: успешно.
- Public SDK scan: нет private dependencies/API violations.

Тесты проверяют: одно чтение изменённого tasks.md, ноль чтений cached snapshots, сохранение неизменённых данных при структурных событиях, rescan после потери событий, root confinement, общий watcher и освобождение последней подписки, удаление/пересоздание openspec, ошибку watcher и ручное восстановление. Отдельно проверены live producer, точечные invalidation, уникальные subscription ids, abort и восстановление через reconcile. Событие thread.active инвалидирует список и связанные детали. Перепривязка остаётся в metadata после последовательных чтений разных changes и обновляет контекст треда.

## Живая проверка в bb

- Плагин собран, перезагружен и находится в состоянии running.
- На открытой панели изменение реального tasks.md обновило карточку и детали с 1/9 на 4/9 без ручного refresh.
- Текущий тред перепривязан с add-openspec-task-browser на watch-openspec-files. Рабочий статус перешёл на новую карточку, вкладка старого change показывает 0 тредов, нового — 1; переходы между ними сохраняют связь.
- После полной перезагрузки страницы компактный режим и связь остались; проверен список из metadata и карточек, а также связанный тред на вкладке деталей.
- Компактный режим скрывает детали, нажатие карточки открывает их с возвратом в список. После закрытия деталей их query размонтируется.
- Выполненное изменение имеет зелёную полосу и явное «✓ Выполнено»; неполная полоса отражает done/total.
- Шапка проверена при ширине 286 px: селекторы 127 px, отдельная строка режима/обновления, scrollWidth не превышает clientWidth.
- Активный индикатор: computed animation-name os-spin, размер 10 px; CSS выключает движение при prefers-reduced-motion.

Живой disconnect/перезапуск машины не вызывался: восстановление и очистка проверены детерминированными тестами. Регрессия reload с уже открытой подпиской исправлена через readiness фонового сервиса; после повторного reload RPC возвращает watchError: null. Скорость spinner — 2.4 секунды на оборот. Новый агент для проверки не запускался. praxis и lore использованы только в read-only benchmark, результаты в openspec-watcher.md.

## Уточнение шапки

Селекторы скрыты за компактной строкой контекста; на 286 px свёрнутая шапка занимает 55 px и не переполняет контейнер. Нажатие раскрывает оба селектора, повторное нажатие/Escape сворачивает их. Иконки режима и обновления имеют Radix tooltips, проверенные также фокусом с клавиатуры. Декоративный логотип убран. Полное окружение видно в tooltip контекста; в узком состоянии показывается только проект.
