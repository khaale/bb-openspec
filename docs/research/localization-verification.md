# Проверка локализации, 0.4.0

Дата: 2026-10-28. bb Plugin SDK 0.6.79.

## Автоматические проверки

Пройдены `npm run typecheck`, `npm test` (31 тест), `npm run build` и `npm run test:stores` (4 интеграционных сценария CLI). Проверены ручной выбор языка, нормализация предпочтений браузера, английский fallback, полнота всех зарегистрированных каталогов, параметры сообщений, русские и английские формы счётчиков, форматирование чисел, локализация собственных кешированных ошибок и сохранение внешних сообщений. Все шаблоны запуска проверены на английский текст с сохранением путей репозитория и требования соблюдать язык артефактов проекта.

## Установленный плагин

- Настройка language переключена через CLI между ru/en/auto; открытый интерфейс меняет язык без reload.
- При переключении ru → en сохраняются экземпляр корневого UI, выбранный change и текст открытой формы запуска. Отдельно проверено сохранение отредактированного prompt при en → ru.
- Auto выбирает английский из реальных предпочтений браузера en-GB; событие languagechange с ru-RU переключает интерфейс на русский. Предпочтения после проверки восстановлены.
- В русском интерфейсе новый prompt начинается с `Implement change add-plugin-localization.`, содержит требование соблюдать project instructions и не содержит русского шаблонного текста.
- Заголовки групп задач из репозитория сохраняют свой язык; локализуются подписи артефактов и собственные статусы.
- При ширине корневой панели 286 px горизонтального переполнения нет (clientWidth = scrollWidth = 286).
- Локальный lang установлен на корне плагина и его формах; глобальный язык документа не изменяется.

После проверки настройка возвращена в Auto. Реальный новый агент не запускался. Native pickers bb и сообщения внешних инструментов остаются вне каталогов плагина.

## Расширение

Каталоги и названия языков регистрируются в `src/messages/index.ts`; список настроек и locale resolution строятся из этого реестра. Инструкция добавления языка находится в README. Дополнительных зависимостей локализации нет.
